# Guide de Démarrage

## Bienvenue sur knitstudio!

Ce guide vous aide à démarrer rapidement.

## Étapes Rapides

### 1. Créer un Projet
Cliquez sur 'Nouveau Projet' dans le tableau de bord

### 2. Ouvrir le Builder
Cliquez sur votre projet pour entrer dans le builder

### 3. Ajouter des Composants
Utilisez le panneau Composants pour glisser des éléments

### 4. Connecter des Données
Ouvrez le panneau Données et ajoutez des sources API

### 5. Publier
Cliquez sur Publier quand c'est prêt

### 6. Exporter le Code
Exécutez 'knit export --project=ID' dans la CLI

## Fonctionnalités Clés

knitstudio comprend:

- 🎨 **Page Designer** — Constructeur visuel glisser-déposer
- ⚡ **Action Flows** — Éditeur de logique visuelle
- 🔗 **Data Binding** — Connectez l'interface à des API réelles
- 🤖 **AI Generation** — Générez des mises en page à partir de texte
- 📦 **Multi-framework Export** — HTML, React et plus
