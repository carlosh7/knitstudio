# 시작 가이드

## knitstudio에 오신 것을 환영합니다!

이 가이드로 빠르게 시작하세요.

## 빠른 시작 단계

### 1. 프로젝트 만들기
대시보드에서 '새 프로젝트'를 클릭하세요

### 2. 빌더 열기
프로젝트를 클릭하여 비주얼 빌더에 입장하세요

### 3. 컴포넌트 추가
컴포넌트 패널을 사용하여 항목을 캔버스로 드래그하세요

### 4. 데이터 연결
데이터 패널을 열고 API 소스를 추가하세요

### 5. 게시
준비가 되면 게시를 클릭하세요

### 6. 코드 내보내기
CLI에서 'knit export --project=ID'를 실행하세요

## 주요 기능

knitstudio에는 다음이 포함됩니다:

- 🎨 **Page Designer** — 비주얼 드래그 앤 드롭 빌더
- ⚡ **Action Flows** — 비주얼 로직 편집기
- 🔗 **Data Binding** — UI를 실제 API에 연결
- 🤖 **AI Generation** — 텍스트에서 레이아웃 생성
- 📦 **Multi-framework Export** — HTML, React 등
