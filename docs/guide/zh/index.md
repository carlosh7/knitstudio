# 入门指南

## 欢迎使用 knitstudio！

本指南将帮助您快速上手。

## 快速开始步骤

### 1. 创建项目
在仪表板上点击'新建项目'

### 2. 打开构建器
点击项目进入可视化构建器

### 3. 添加组件
使用组件面板将项目拖到画布上

### 4. 连接数据
打开数据面板并添加API源

### 5. 发布
准备就绪后点击发布

### 6. 导出代码
在CLI中运行'knit export --project=ID'

---

## 主要功能

knitstudio 包括：

- 🎨 **Page Designer** — 可视化拖放构建器
- ⚡ **Action Flows** — 可视化逻辑编辑器
- 🔗 **Data Binding** — 将UI连接到真实API
- 🤖 **AI Generation** — 从文本提示生成布局
- 📦 **Multi-framework Export** — HTML、React等
