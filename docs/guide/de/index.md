# Erste Schritte

## Willkommen bei knitstudio!

Diese Anleitung hilft Ihnen beim schnellen Einstieg.

## Schnellstart-Schritte

### 1. Projekt erstellen
Klicken Sie auf 'Neues Projekt' im Dashboard

### 2. Builder öffnen
Klicken Sie auf Ihr Projekt, um den Builder zu öffnen

### 3. Komponenten hinzufügen
Verwenden Sie das Komponenten-Panel zum Ziehen von Elementen

### 4. Daten verbinden
Öffnen Sie das Daten-Panel und fügen Sie API-Quellen hinzu

### 5. Veröffentlichen
Klicken Sie auf Veröffentlichen

### 6. Code exportieren
Führen Sie 'knit export --project=ID' in der CLI aus

---

## Hauptfunktionen

knitstudio enthält:

- 🎨 **Page Designer** — Visueller Drag-&-Drop-Builder
- ⚡ **Action Flows** — Visueller Logik-Editor
- 🔗 **Data Binding** — Verbinden Sie die UI mit echten APIs
- 🤖 **AI Generation** — Generieren Sie Layouts aus Text
- 📦 **Multi-framework Export** — HTML, React und mehr
