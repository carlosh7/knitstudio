# Getting Started Guide

## Welcome to knitstudio!

This guide helps you get started quickly.

## Quick Start Steps

### 1. Create a Project
Click 'New Project' on the dashboard

### 2. Open the Builder
Click your project to enter the visual builder

### 3. Add Components
Use the Components panel to drag items onto the canvas

### 4. Connect Data
Open the Data panel and add API sources

### 5. Publish
Click Publish when ready

### 6. Export Code
Run 'knit export --project=ID' in the CLI

---

## Key Features

knitstudio includes:

- 🎨 **Page Designer** — Visual drag & drop builder
- ⚡ **Action Flows** — Visual logic editor
- 🔗 **Data Binding** — Connect UI to real APIs
- 🤖 **AI Generation** — Generate layouts from text prompts
- 📦 **Multi-framework Export** — HTML, React, and more
