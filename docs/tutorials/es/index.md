# Tutoriales

Tutoriales paso a paso para dominar knitstudio:

### 🌐 Crear un Proyecto
Haz clic en 'Nuevo Proyecto' en el panel

### 🎨 Agregar Componentes
Usa el panel de Componentes para arrastrar elementos

### 🔗 Conectar Datos
Abre el panel de Datos y agrega fuentes API

### 🤖 Generación con IA
Crea diseños describiendo lo que quieres

### 📦 Exportar Código
Ejecuta 'knit export --project=ID' en la CLI
