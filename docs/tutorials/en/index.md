# Tutorials

Step-by-step tutorials to master knitstudio:

### 🌐 Create a Project
Click 'New Project' on the dashboard

### 🎨 Add Components
Use the Components panel to drag items onto the canvas

### 🔗 Connect Data
Open the Data panel and add API sources

### 🤖 AI Generation
Create layouts by describing what you want

### 📦 Export Code
Run 'knit export --project=ID' in the CLI
