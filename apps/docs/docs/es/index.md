# Guía de Inicio

## ¡Bienvenido a knitstudio!

Esta guía te ayuda a empezar rápidamente.

## Pasos Rápidos

### 1. Crear un Proyecto
Haz clic en 'Nuevo Proyecto' en el panel

### 2. Abrir el Builder
Haz clic en tu proyecto para entrar al builder

### 3. Agregar Componentes
Usa el panel de Componentes para arrastrar elementos

### 4. Conectar Datos
Abre el panel de Datos y agrega fuentes API

### 5. Publicar
Haz clic en Publicar cuando esté listo

### 6. Exportar Código
Ejecuta 'knit export --project=ID' en la CLI

---

## Características Clave

knitstudio incluye:

- 🎨 **Page Designer** — Constructor visual de arrastrar y soltar
- ⚡ **Action Flows** — Editor de lógica visual
- 🔗 **Data Binding** — Conecta la UI a APIs reales
- 🤖 **AI Generation** — Genera diseños desde texto
- 📦 **Multi-framework Export** — HTML, React y más
