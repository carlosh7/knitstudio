# Tutoriais

Tutoriais passo a passo para dominar o knitstudio:

### 🌐 Criar um Projeto
Clique em 'Novo Projeto' no painel

### 🎨 Adicionar Componentes
Use o painel de Componentes para arrastar itens

### 🔗 Conectar Dados
Abra o painel de Dados e adicione fontes de API

### 🤖 Geração com IA
Crie layouts descrevendo o que você quer

### 📦 Exportar Código
Execute 'knit export --project=ID' na CLI
