# Guia de Início

## Bem-vindo ao knitstudio!

Este guia ajuda você a começar rapidamente.

## Passos Rápidos

### 1. Criar um Projeto
Clique em 'Novo Projeto' no painel

### 2. Abrir o Builder
Clique no projeto para entrar no builder

### 3. Adicionar Componentes
Use o painel de Componentes para arrastar itens

### 4. Conectar Dados
Abra o painel de Dados e adicione fontes de API

### 5. Publicar
Clique em Publicar quando estiver pronto

### 6. Exportar Código
Execute 'knit export --project=ID' na CLI

---

## Recursos Principais

knitstudio inclui:

- 🎨 **Page Designer** — Construtor visual de arrastar e soltar
- ⚡ **Action Flows** — Editor de lógica visual
- 🔗 **Data Binding** — Conecte a interface a APIs reais
- 🤖 **AI Generation** — Gere layouts a partir de texto
- 📦 **Multi-framework Export** — HTML, React e mais
