# はじめに

## knitstudioへようこそ！

このガイドですぐに始められます。

## クイックスタート手順

### 1. プロジェクト作成
ダッシュボードで「新規プロジェクト」をクリック

### 2. ビルダーを開く
プロジェクトをクリックしてビジュアルビルダーを開く

### 3. コンポーネント追加
コンポーネントパネルを使ってアイテムをドラッグ

### 4. データ接続
データパネルを開いてAPIソースを追加

### 5. 公開
準備ができたら「公開」をクリック

### 6. コード出力
CLIで「knit export --project=ID」を実行

---

## 主な機能

knitstudioには以下が含まれます:

- 🎨 **Page Designer** — ビジュアルドラッグ＆ドロップビルダー
- ⚡ **Action Flows** — ビジュアルロジックエディター
- 🔗 **Data Binding** — UIを実際のAPIに接続
- 🤖 **AI Generation** — テキストからレイアウトを生成
- 📦 **Multi-framework Export** — HTML、Reactなど
