# Tutorial

Tutorial passo passo per padroneggiare knitstudio:

### 🌐 Creare un Progetto
Clicca su 'Nuovo Progetto' nel dashboard

### 🎨 Aggiungere Componenti
Usa il pannello Componenti per trascinare elementi

### 🔗 Connettere Dati
Apri il pannello Dati e aggiungi fonti API

### 🤖 Generazione AI
Crea layout descrivendo ciò che vuoi

### 📦 Esportare Codice
Esegui 'knit export --project=ID' nella CLI
