# Guida Introduttiva

## Benvenuto in knitstudio!

Questa guida ti aiuta a iniziare rapidamente.

## Passi Rapidi

### 1. Creare un Progetto
Clicca su 'Nuovo Progetto' nel dashboard

### 2. Aprire il Builder
Clicca sul progetto per entrare nel builder

### 3. Aggiungere Componenti
Usa il pannello Componenti per trascinare elementi

### 4. Connettere Dati
Apri il pannello Dati e aggiungi fonti API

### 5. Pubblicare
Clicca su Pubblica quando sei pronto

### 6. Esportare Codice
Esegui 'knit export --project=ID' nella CLI
